O que é Cloud Computing?

🌐

Definição: Cloud Computing é a entrega de serviços de computação através da Internet, incluindo (mas não se limitando a): Servidores e desktops virtualizados, armazenamento, bases de dados, redes, software, agentes/modelos de IA, zonas DNS e ferramentas de análise, etc.

Características Principais:

  • ✅ Self-service sob demanda - Provisione recursos quando necessário
  • ✅ Acesso amplo à rede - Acessível de qualquer lugar
  • ✅ Pool de recursos - Recursos partilhados entre múltiplos clientes
  • ✅ Elasticidade rápida - Escalar para mais ou menos recursos conforme necessário
  • ✅ Serviço medido - Pague apenas pelo que usa

Evolução da Infraestrutura de TI

📦 On-Premises → 🖥️ Virtualização → ☁️ Cloud

Aspecto On-Premises Virtualização Cloud
Investimento CAPEX* elevado CAPEX* médio OPEX** (pay-as-you-go)
Escalabilidade Limitada e lenta Melhorada Ilimitada e instantânea
Manutenção Total responsabilidade Responsabilidade parcial Responsabilidade do provider
Tempo de Deploy Semanas/Meses Dias/Semanas Minutos/Horas
*CAPEX: Capital Expenditure (Investimento em infraestrutura)

**OPEX: Operational Expenditure (Custos operacionais)

Modelos de Serviço Cloud

IaaS

Infrastructure as a Service

  • Máquinas Virtuais

Exemplo: Azure VMs, AWS EC2

PaaS

SaaS

Modelos de Implementação Cloud

☁️ Cloud Pública

  • Recursos são propriedade do provider e operados por ele
  • Acesso via Internet (opcional: via VPN)
  • Exemplos: Azure, AWS, Google Cloud
  • ✅ Menor custo | ❌ Menor controlo

🏢 Cloud Privada

  • Infraestrutura dedicada a uma única organização
  • Pode estar on-premises ou hosted
  • Maior controlo e personalização
  • ✅ Maior segurança | ❌ Maior custo

🔄 Cloud Híbrida

  • Combinação de cloud pública e privada
  • Dados e aplicações podem mover-se entre ambas
  • Flexibilidade máxima
  • ✅ Melhor dos dois mundos | ❌ Maior complexidade

Estrutura Organizacional do Azure

📊 Hierarquia Azure

Management Groups - Gestão de múltiplas subscrições (assinaturas)
Subscriptions - Limite de faturação e controlo de acesso
Resource Groups - Agrupamento lógico de recursos
Resources - VMs, Storage, Databases, etc.

Conceitos Fundamentais:

  • Resource: Item gerenciável disponível no Azure (VM, DB, etc.)
  • Resource Group: Container que agrupa recursos relacionados
  • Subscription: Agrupamento lógico de recursos para faturação
  • Management Group: Gestão hierárquica de subscriptions

Regiões e Zonas de Disponibilidade

🌍 Regiões Azure

Uma região é uma área geográfica que contém pelo menos um datacenter (normalmente três, separados por uma distância de 50km).

Regiões em África (ambas possuem 3 AZ's):

  • 🇿🇦 South Africa North (Johannesburg)
  • 🇿🇦 South Africa West (Cape Town)

🏢 Zonas de Disponibilidade

Datacenters fisicamente separados dentro de uma região Azure.

  • ✅ Proteção contra falhas de datacenter
  • ✅ Alta disponibilidade (99.99% SLA)
  • ✅ Replicação síncrona de dados
  • ✅ Latência < 2ms entre zonas
Best Practice: Sempre distribua recursos críticos entre múltiplas zonas de disponibilidade!

Gestão de Custos no Azure

💰 Modelo de Preços:

  • Pay-as-you-go - Paga pelo que usa
  • Reserved Instances - Até 72% desconto
  • Spot VMs - Até 90% desconto
  • Dev/Test Pricing - Preços reduzidos para desenvolvimento

🎯 Dicas para Economizar:

# 1. Desligar VMs quando não estiver usando az vm deallocate --resource-group RG --name VM # 2. Usar tamanhos adequados Standard_B1s # Para testes (barato) Standard_B2s # Para desenvolvimento # 3. Configurar auto-shutdown Portal → VM → Auto-shutdown → Enable # 4. Monitorar custos regularmente Portal → Cost Management → Cost analysis
⚠️ Atenção: Sempre delete recursos não utilizados para evitar custos inesperados!
